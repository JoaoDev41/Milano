# 🍷 Milano

Website desenvolvido com foco em design, interatividade e experiências modernas para a web.

O projeto explora animações avançadas e interações baseadas na rolagem da página para proporcionar uma experiência visual mais dinâmica e imersiva.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- GSAP
- ScrollTrigger
- ScrollSmoother
- SplitText

## ✨ Destaques do projeto

- Interface moderna
- Layout responsivo
- Animações avançadas com GSAP
- Interações baseadas no scroll
- Rolagem suave com ScrollSmoother
- Animações de textos utilizando SplitText
- Transições e movimentos integrados à experiência da página
- Estrutura organizada em HTML, CSS e JavaScript

## 🎯 Objetivo

O projeto foi desenvolvido para explorar possibilidades de interação e movimento no desenvolvimento Front-End, utilizando animações como parte da experiência do usuário sem comprometer a organização e a usabilidade da interface.
